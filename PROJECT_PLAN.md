# Project Plan

## Vision
Build a reusable tool that helps researchers prioritize RNA aptamer candidates
for heavy-metal fluorescent biosensors.

## Phase 1: Help BioMod
- Understand the team’s current candidate-selection workflow
- Build a literature-based prototype
- Produce a ranked candidate list for the next testing round
- Collect standardized wet-lab results

## Phase 2: Improve with team data
- Add fluorescence fold-change labels
- Retrain after each testing round
- Add uncertainty and error analysis

## Phase 3: Make it reusable
- Build a simple public web app
- Publish dataset, model card, and documentation
- Allow others to submit sequences and results
