# AptaSwitch
ML-assisted prioritization of RNA aptamer candidates for heavy-metal, protein and gene fluorescent biosensors.

## Why this exists

Our BioMod team is designing RNA aptamer-based switches that produce a fluorescence
signal in response to heavy-metal ions such as Pb2+ and Ni2+. Synthesizing and testing
every candidate is slow and expensive.

AptaSwitch aims to help the team prioritize which RNA sequences to test first.

## Current status

Phase 1: literature-data prototype for the BioMod team.

## What it will do

- Collect and standardize public aptamer data
- Extract sequence and predicted-structure features
- Rank candidate RNA sequences
- Explain the main features behind each prediction
- Record team experimental results for future model improvement

## What it does not do

- It does not replace experimental validation.
- It does not guarantee that a high-scoring sequence will work.
- It does not yet predict performance in every buffer, fluorophore, or assay condition.
