# Decision Log

## 2026-10-28 — Start with literature data
**Decision:** Build the first model using public aptamer data and published results.
**Reason:** The team does not yet have enough in-house labeled data.
**Consequence:** The first model will be a prioritization tool, not a validated predictor.

## 2026-10-28 — Separate Pb2+ and Ni2+ models initially
**Decision:** Train separate models for each metal at first.
**Reason:** Binding mechanisms and assay behavior may differ.
**Consequence:** More manageable interpretation and fewer confounding effects.
